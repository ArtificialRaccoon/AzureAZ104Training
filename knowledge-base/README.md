# AZ-104: Microsoft Azure Administrator Knowledge Base

This knowledge base provides a comprehensive personal training repository for the AZ-104 certification, combining two authoritative pillars:
1. **Primary Curriculum**: [Course AZ-104T00-A: Microsoft Azure Administrator](https://learn.microsoft.com/en-us/training/courses/az-104t00) (Official Microsoft Learn Course, 6 Learning Paths, 28 Modules, ~18.1 hours).
2. **Certification Strategy & Exam Traps**: *Exam Ref AZ-104 Microsoft Azure Administrator* (Charles Pluta, 3rd Edition, Pearson Education, 2024; Chapters 1–6, 361 pages).

- **Total Learning Paths:** 6
- **Total Modules:** 28 (Each with Microsoft Learn content + Charles Pluta Exam Ref deep dives)
- **Total Curriculum Duration:** ~18.1 hours of structured material
- **Verification Guarantee:** 100% verified against Microsoft Learn APIs and Exam Ref physical page anchors with zero hallucinations.
